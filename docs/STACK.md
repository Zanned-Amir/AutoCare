# Stack and versions

Checked on 2026-10-17. Pin these; upgrade on purpose, not by accident.

## Backend

| Piece | Version | Why |
| --- | --- | --- |
| Java | **25 (LTS)** | Current LTS. Java 27 exists but is not LTS; 21 is older LTS without the newer language features. |
| Spring Boot | **4.1.1** | Latest stable line (4.2 is still milestone). Boot 4 = Spring Framework 7, Jackson 3, Hibernate 7.4, modular starters. |
| Spring Modulith | **2.1.1** | Module boundaries verified in a test, event publication registry (reliable in-process events), module docs. This is what makes "facades now, microservices later" enforceable. |
| Spring Security | managed by Boot | OAuth2 resource server with JWT (Nimbus). No extra JWT library. |
| PostgreSQL | **18** | One schema per module. |
| Flyway | managed by Boot (12.4) | One migration folder per module, timestamp versions. |
| Redis | **8.6** | Spring Cache, permission cache `perms:{orgId}:{userId}`, rate limits / send cooldowns. |
| MinIO / S3 | AWS SDK v2 **2.56** | Same client for MinIO now and S3 later (path-style switch). |
| springdoc-openapi | **3.1.1** | Swagger UI for Boot 4. |
| MapStruct | **1.6.3** | Entity -> DTO mapping without reflection. |
| Lombok | managed by Boot | Boilerplate on entities and services. |
| Testcontainers | managed by Boot (2.0) | Real Postgres/Redis in tests. |
| Spring Java Format | **0.0.48** | One formatting style, checked in `validate`. |

## Frontend

| Piece | Version | Instead of (toutestcasa) | Why |
| --- | --- | --- | --- |
| Angular | **22.2** | React 19 + React Router | Standalone + zoneless + signals by default. |
| TanStack Query (Angular) | **5.104** (`@tanstack/angular-query-experimental`) | React Query | Same mental model and API (`injectQuery`, `injectMutation`, query keys, invalidation). The package is still named "experimental" but is widely used; pin the version. |
| NgRx Signals | **22.0** (`signalStore`) | Zustand | Small, signal-based, per-feature stores, no actions/reducers boilerplate. Classic NgRx Store would be overkill. |
| Angular Signal Forms | built into `@angular/forms` 22 (stable since 22.0) | React Hook Form | Signal-based, typed, tracks dirty/touched/valid per field, `reset(value)`. |
| Zod | **4.6** | Zod | Works natively: Signal Forms accept any Standard Schema via `validateStandardSchema`. Same schemas can validate API responses if needed. |
| Tailwind CSS | **4.3** | Tailwind 4 | Generated by `ng new --style tailwind`; tokens in `@theme`. |
| Vitest | 5 | Vitest | Angular 22 default test runner. |
| angular-eslint | latest | ESLint | `npm run lint`. |

Not chosen, on purpose:

- **Reactive Forms**: still fine, but Signal Forms are the direct equivalent of React Hook Form + Zod and are stable in v22.
- **NgRx Store / Effects**: too heavy once server state lives in TanStack Query.
- **CASL**: possible (`@casl/angular`), but the permission model is plain `resource:action` strings with wildcards; `grants()` (12 lines, same rule as the backend) is enough. Revisit if conditions per record appear.
- **Angular Material / PrimeNG**: would fight the custom tokens. Build small components in `shared/ui`; add Angular CDK if you need overlays/dialogs.

## Infrastructure

`docker-compose.dev.yml` at the repo root, adapted from toutestcasa: Postgres 18, Redis 8.6.1, MinIO (same mirror image), Mailpit, plus the API under the `app` profile. Every variable has a default; override in `.env` (`.env.example`).
